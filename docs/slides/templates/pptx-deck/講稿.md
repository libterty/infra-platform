# 簡報範本 講稿

這份是範本的講稿，也是投影片備忘稿的來源：`build.js` 會讀每一頁「##」底下、「出處：」之前的文字，放進對應頁的備忘稿。頁數要跟 `build.js` 的頁數一樣，不一樣時 build 會報錯。

## 1｜封面

開場先講今天要談什麼、為什麼現在談，以及最後想請聽眾做什麼決定。

## 2｜標題直接寫結論

第二頁就講結論：問題是什麼、建議怎麼做、今天要聽眾決定什麼。後面的每一頁都是在支撐這三句。

## 3｜三張卡片：並列三個觀察

適合放三個並列的觀察。最重要的那張用強調色，結語一行收尾。

出處：
- 這裡放講者查證用的出處，不會進備忘稿

## 4｜左右對照：兩個選項或兩種情況

兩個選項或兩種情況並排比較。比較完的判斷寫在下方結語。

## 5｜流程：三個步驟加箭頭

三個步驟由左到右，最後一格是結果。外部引用放在左下角。

## 6｜表格：現在與改變後

前後對照用這頁。右欄用強調色，表格下方寫限制或前提。

## 7｜分層：由上往下的四層

適合講架構或組織分層。右側括號把四層分成兩組。

## 8｜編號清單：列出要回答的問題

列出接下來要回答的問題，右側標出答案在哪一頁。

## 9｜四個階段，達到條件才進下一階

分階段推動用這頁。第一階段用強調色，結語寫推進的原則。

## 10｜需要確認的兩件事

最後一頁寫要聽眾決定的事，以及決定之後的下一步：誰做、做什麼、什麼時候檢查。
